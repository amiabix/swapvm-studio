# SwapVM Studio specification

Approved direction: glasses/voice to generated pricing module, counterexample-guided repair, reviewed authorization, atomic deployment and real Aqua swap, author attribution. SwapVM release/1.1 pinned ac06e1bac021cd1983dc7c44d1f69b4b8861a945. Solidity 0.8.30 / Cancun. Test fixtures never represent a live model or sponsor payment.

Generated modules are externally called using STATICCALL in both quote and swap. Interface: quote(uint256 amount, bool exactIn, uint256 balanceIn, uint256 balanceOut, bytes calldata params) external view returns (uint256 amountIn, uint256 amountOut). They do not receive execution mode, query, program counter, accounting register or private signing material. A trusted instruction validates returned amounts, controls accounting and records author identity from pinned module registration. Native untrusted opcodes are forbidden in accepted programs. Restrict main execution to supported standard ERC20s; no arbitrary callbacks in the accepted path. Bound module gas and parameter sizes.

Use official Aqua and SwapVM for token settlement. Author fees and exact-in/out calculations must agree. Signed transaction authorization binds chain, executor/router, module init/runtime code commitment, parameters, token pair, maximum input, minimum output, fee cap, nonce and deadline. CREATE2 address includes deployer, salt and initcode hash. State writes from generated modules revert; a failing swap rolls back deployment, author fees and nonce consumption.

Verification: fixed harness outside model control; retain counterexamples; report sample ranges, tolerances, skips and seeds. Cover symmetry, additivity where applicable, quote/swap consistency through actual swaps, monotonicity, rounding, real liquidity sufficiency and supported-domain liveness. Do not label fuzzing a proof. Model repairs are bounded and fail closed. Any replay fixture must be visible as such. Generated source is compiled in isolation without FFI and never allowed to alter contracts/tests/configuration.

ENSv2 Sepolia: release manifest pins artifact/report, permissions enforced by trusted code or explicit authenticated pinning. Hedera: real Blocky402 x402 paid compute endpoint and HCS anchoring where credentials available; independent signed verifier report remains trusted, no crosschain trustlessness claim. Glasses use phone microphone routing/toolkit depending on available hardware; no fabricated wearable integration.
